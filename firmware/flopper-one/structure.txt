✅MenuNode
  name: string
  children: [MenuNode | App]

✅App (subclass of MenuNode, implements InputHandler)
  onEnter()
  onExit()
  tick()
  draw()
  exit()         calls onExit, pops input stack, returns to menu

✅InputHandler (interface)
  onInput(event): null

✅InputDispatcher (singleton) Handles debouncing and dispatches on rising edge.
  stack: [InputHandler]
  push(handler), pop(handler)
  dispatch(event) -> top of stack only


✅MenuManager (singleton, implements InputHandler)
  root: MenuNode
  currentNode: MenuNode
  activeApp: App | null
  handles: UP/DOWN/SELECT/BACK navigation
  on SELECT of App -> app.onEnter(), push app to InputDispatcher
  on BACK -> navigate up tree

✅Display (singleton)
  primitive drawing (+text) only
  owned entirely by whoever is on top of InputDispatcher
  Think:
  clear(color)
  drawText(x, y, str, color, size)
  drawRect(x, y, w, h, color, radius)
  fillRect(x, y, w, h, color)



✅UI 
    UI drawing methods. Think:
    drawList(display, items, selectedIndex)
    drawConfirm(display, message)
    drawStatusMessage(display, message)

Global loop:
  poll InputDispatcher
  tick menumanager, which ticks the current app if app open
  ... that's it lol
